# Shubham Singh

Software Development Engineer II at Amazon, based in Seattle.

I build production AI and compliance infrastructure: agentic Q&A systems, hybrid retrieval, control launch workflows, regulatory data pipelines, and the backend surfaces that make those systems auditable and operable.

What I care about most is the production path. Agentic systems are only useful when the surrounding engineering is solid: state, idempotency, audit trails, permission boundaries, evaluation, observability, and clear human review loops.

- Frontend surfaces for operators reviewing artifacts, evidence, workflow state, and approvals
